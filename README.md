# Centrum szkolne — 1P, grupa 1

Strona dla ucznia ZSMEiE w Toruniu. Plan lekcji, odliczanie lekcji i przerw, planer nauki, fiszki z quizem, kalkulator średniej i kopia zapasowa.

## Uruchomienie

Strona nie wymaga instalowania bibliotek ani budowania. Opublikuj pliki w GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

## Dane

Plan pochodzi z https://zsmeie.torun.pl/plan/#1P, pobrany 24.09.2026, obowiązuje od 14.09.2026. Grupa 1 potwierdzona przez użytkownika: piątek 08:00, strony internetowe, KC, sala 18. Religia jest opcjonalna w ustawieniach. Plan nie synchronizuje się automatycznie; zastępstwa i dni wolne nie pochodzą z dziennika.

Własne zadania, oceny i fiszki pozostają w localStorage przeglądarki. Kopie można eksportować i importować w ustawieniach. Usunięcie danych witryny usuwa zapis. Dane nie synchronizują się między urządzeniami.

Quiz korzysta z własnych fiszek i samooceny odpowiedzi. Kalkulator nie przewiduje decyzji nauczyciela o ocenie końcowej.
